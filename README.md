# Event Planner

Учебный сервис для организации небольших мероприятий: встреч, мастер-классов и вечеров настольных игр. Организатор публикует событие и управляет участниками, пользователи находят мероприятия или принимают приглашения.

Бэкенд реализован и доступен через Swagger. React-фронтенд — следующий этап.

## Возможности

- Авторизация через JWT, refresh-сессии и выход с одного или всех устройств.
- Черновики и публикация мероприятий, публичная витрина с поиском и пагинацией.
- Публичные, доступные по ссылке и приватные мероприятия.
- Регистрация, модерация заявок и приглашения с контролем свободных мест.
- Фоновые email-уведомления, Redis-кэш и ограничение частоты запросов.

## Стек

TypeScript, NestJS, PostgreSQL, Prisma, Redis, BullMQ, Nodemailer.
Проверки и окружение: Jest, Supertest, Testcontainers, Docker Compose, GitHub Actions.

## Быстрый запуск

Нужен работающий Docker с Compose v2. Команды выполняются из корня репозитория.

Для нового клона скопируй настройки; существующий `.env` не перезаписывай:

```bash
cp apps/api/.env.example apps/api/.env
```

В `.env` заполни `JWT_ACCESS_SECRET` и `JWT_REFRESH_SECRET` разными случайными значениями длиной от 32 символов. Для каждого можно использовать `openssl rand -hex 32`. Секреты не добавляй в Git.

Если API или worker уже запущены вне Docker, останови их, затем выполни:

```bash
docker compose up --build -d
```

Compose поднимет PostgreSQL, Redis, Mailpit, миграции, API и worker. Завершение `migrate` со статусом `Exited (0)` — нормально.

- [Swagger](http://localhost:3000/api/docs) — документация и проверка API.
- [Mailpit](http://localhost:8025) — просмотр отправленных писем.

Окружение предназначено для локальной разработки, не для production. Пользователи автоматически не создаются — зарегистрируй их через Swagger.
