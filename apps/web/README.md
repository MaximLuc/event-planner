# Event Planner — фронтенд

React + TypeScript + Vite. Пока реализована стартовая страница без подключения к API.

## Запуск

Из папки `apps/web`:

```bash
pnpm install
pnpm dev
```

Открой адрес, который Vite выведет в терминале.

## Проверки

```bash
pnpm lint
pnpm build
```

`pnpm preview` запускает локальный просмотр готовой сборки после `pnpm build`.

Описание проекта и запуск бэкенда — в [основном README](../../README.md).
